Privacy Policy

Derek Halvern Studio. Last updated October 12, 2026.

What this app is

Derek Halvern Studio is a private tool used only by the owner of the Derek Halvern YouTube channel. It is not offered to the public, and no one else can sign in to it.

What data it uses

With the owner's permission, the app reads messages in the owner's own Gmail account, for example sign-in codes sent by websites the channel uses. It does not access anyone else's account.

How the data is used

Email content is used only to complete those sign-ins and production tasks for the channel. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage

The app does not keep copies of emails. Access tokens are stored privately and can be revoked at any time in the Google Account's security settings.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
